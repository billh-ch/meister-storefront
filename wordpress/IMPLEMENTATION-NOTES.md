# Implementation coordination

- Independent-review fixes: all text entry points enforce UTF-8 byte limits (`name` 1000; `short_description`/`description` 100000). Generate apply reserves the whole batch using `meister_translation_generate_lock_<ID>` before existing-locale checks/provider calls; separate import locks permit guarded draft persistence. `finally` releases owned reservations after success/errors; dry runs neither lock nor call providers. Crash recovery requires checking the exact operation is stopped before removing a specific generation/import option, never automatic expiry.
- Woo REST preparation can contain unserialized `WC_Meta_Data` objects, not just arrays. The response filter reads object keys without converting unrelated metadata objects. The pre-insert guard resolves incoming metadata IDs through persisted `get_metadata_by_mid('post', $id)` and checks both product ownership and the protected key: Woo controller preparation can already have renamed/deleted the in-memory object. Standalone regressions cover both post-preparation bypasses, ID-only updates, and unrelated/foreign/missing IDs without database writes. Parent owns the actual read-only Woo runtime smoke; no site changes by this subagent.
- CLI safety flags (`apply`, `publish`, `overwrite`, `confirm-cost`) accept only boolean values; explicit `false` is not presence-based consent. Valued forms such as `--apply=false` and empty/numeric/null/array values are rejected, rather than accidentally applying/publishing/overwriting or consenting to paid generation. Import CLI tests use an in-memory stream wrapper (no fixture files/database writes); explicit boolean publication and false/dry-run/manual-preservation paths are covered.
- Hash contract and fixture available in `wordpress/HASH-CONTRACT.md` and `wordpress/fixtures/product-translations-canonical.json` now. Raw authenticated REST field name is `meister_translation_source`.
- Provider recommendation: `gpt-5-mini` (snapshot `gpt-5-mini-2025-08-07`, configurable), based on parent's successful real technical-Greek sample and official pricing of $0.25 input/$2 output per 1M tokens. `gpt-5.4-mini` is a configurable higher-cost evaluation alternative ($0.75/$4.50). No deprecation assertion is made; assess official lifecycle before future updates. Parent tested `reasoning.effort: low`; plugin uses that setting. Review technical Greek quality before publishing.
- Plugin uses server-only `OPENAI_API_KEY` wp-config constant or environment variable; `MEISTER_TRANSLATION_MODEL` overrides model. Never stores credentials in admin/database. Responses API fixed HTTPS endpoint, `store:false`, strict `text.format` schema, bounded output. No service enrollment.
- Temporary WP CLI loading is supported: plugin bootstrap can be required with `wp --path=/var/www/html --user=<authorized-admin-id> --require=/home/pi/meister-translation-work/meister-product-translations/meister-product-translations.php eval-file <private-smoke-script.php>`. No activation required; bootstrap registers hooks/classes and CLI commands while Woo loads normally. This only works after the parent deliberately stages files; this subagent has not staged/installed/written anything on Pi (tests stream stdin to standalone PHP only). Use `require_once` when already active.
- Dry-run CRUD: `MT_Service::import($job)`; explicit draft apply: `MT_Service::import($job,['apply'=>true])`. Read back `wc_get_product($id)->get_meta('meister_translations',true,'edit')`; separately compare originals/IDs/commerce fields. Parent must obtain explicit authorization before live writes. Do not print credentials.
