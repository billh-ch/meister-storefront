# Product Compare Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Compare up to four same-category products, including attributes added later.
**Architecture:** Small external selection store, strict public compare-data API, shared controls and responsive semantic comparison table. Browser-local selection persists independently of wishlist/account state.
**Tech Stack:** Next.js 16.2.12, React 19, TypeScript, WooCommerce, Playwright.
**Spec:** docs/superpowers/specs/2026-10-10-compare-design.md

## Global Constraints
- No plugins/new dependencies; preview only.
- Up to four same-category whole products; 44px controls; fit 320px.
- Published products and visible attributes only; honest missing/error states.

## Review Focus
- Never infer dimensions units or compare variant prices as selected prices.
- Dynamic attribute identity must survive label changes and custom attribute ordering.
- Corrupt storage, blocked writes and cross-tab updates must not crash or silently lose selection.
- Outages/private/deleted IDs must retain removable entries without fabricating catalog data.
- Comparison tray must not obstruct native cart dialogs or PDP mobile purchasing.
