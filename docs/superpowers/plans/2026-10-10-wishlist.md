# Wishlist Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Save products as a guest or across devices with an account.
**Architecture:** Browser guest IDs plus a customer-scoped pending journal; session-authenticated API and independent WooCommerce customer metadata updates. Shared client provider drives hearts, count, and wishlist page.
**Tech Stack:** Next.js 16.2.12, React 19, TypeScript, WooCommerce, Playwright.
**Spec:** docs/superpowers/specs/2026-10-10-wishlist-design.md

## Global Constraints
- 44px heart targets; fit mobile at 320px.
- No new dependencies; no production release in this task.
- Private wishlist responses are not cached and never trust a supplied customer ID.

## Review Focus
- Failed merge must preserve guest saves.
- Concurrent changes to different products must preserve both.
- Sign-out/account changes must hide the prior customer's wishlist.
- Deleted/private products must remain removable without exposing catalog details.
- Storage failure must produce an honest message instead of claiming persistence.
